# Admin Guide

P0 admin pages are scaffolded with protected route access. Production admin workflows must support:

- Create organisations.
- Create recruitments.
- Add multiple post-level jobs.
- Add post-specific eligibility rules.
- Preview, review, publish, unpublish, expire and archive.
- Record audit logs for all publishing changes.

Imported or extracted data must enter draft or review state. It must not be published automatically.
